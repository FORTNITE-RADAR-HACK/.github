## ❓ FAQ

**Do I need to run it as Administrator?**

No. This map reference guide does not attach to the game or interact with its process.

**Can antivirus software flag downloaded files?**

Only download files from sources you trust. Review any security warning carefully before opening an unfamiliar file.

**Does it work on Windows 11?**

The reference materials are intended for use on Windows 10 and Windows 11.

**Does the radar reveal enemy positions?**

No. It provides map-learning resources and does not reveal opponents, hidden loot, or live match information.

**Are map references updated?**

Map information can change between Fortnite updates. Check the project materials against the current in-game map.
